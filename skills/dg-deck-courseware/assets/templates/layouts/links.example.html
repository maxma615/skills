RDK 小课堂 2-01
认识 BPU · 配套资源03 / 24
开始之前，先把资料准备好。本章的主角，是 GitHub 上的 RDK Model Zoo。遇到概念问题，就去文档资源中心，查算法工具链的文档：X5 看"PTQ 转换原理及流程"，S 系列看"hb_compile 工具"这一页；板端命令的用法，在"hrt_model_exec 工具介绍"里。这节课不需要电脑端的工具链，只要你的板子能 SSH 登录、能联网就可以。
