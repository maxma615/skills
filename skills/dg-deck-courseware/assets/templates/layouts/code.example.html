Board Check

先认清手上的板子

两条命令四块板通用，读的文件和 Model Zoo 自动识别板卡一致。

① BPU 有几个核root@rdk: ~
$ cat /sys/devices/system/bpu/core_num
$ ls /sys/devices/system/bpu/
要点

X5、S100、S100P 输出 1；S600 输出 4，能看到 bpu0..bpu3。

② 板卡身份root@rdk: ~
$ cat /sys/class/boardinfo/soc_name \
/sys/class/socinfo/soc_name \
2>/dev/null | tr -d '\0'
要点

X5 → X5U；S 系列 → S100 / S100P / S600。--target auto 就靠它。

认识 BPU · 认清板卡10 / 24
那怎么确认自己手上是哪块板呢？两条命令。第一条，cat 一下 core_num，看 BPU 有几个核：X5、S100、S100P 都是 1，S600 是 4，还能看到 bpu0 到 bpu3 四个目录。第二条，读 soc_name：X5 会输出 X5U，S 系列分别输出 S100、S100P、S600。这条命令读的文件和顺序，跟 Model Zoo 自动识别板卡的逻辑是一样的。所以跑 sample 的时候，target 设成 auto，它就能自己判断，平时不用手动指定。

下载模型并查看信息

在仓库根目录执行；换板时把 x5 改成 s100 / s100p / s600。

① 下载 ResNet-18root@rdk: ~
$ git clone https://github.com/D-Robotics/rdk_model_zoo.git
$ cd rdk_model_zoo
$ bash samples/vision/resnet/model/download.sh x5 18
要点

X5 得到 resnet18_bayese_224x224_nv12.bin；S 系列得到对应的 .hbm（nashe / nashm / nashp）。

② 查看模型信息root@rdk: ~
$ hrt_model_exec model_info \
--model_file <模型文件>
要点

四块板都已预装 hrt_model_exec，不用另外安装。

实测 BPU 推理性能

四块板语法一致；另开一个终端看 BPU 使用率。

③ 纯推理性能root@rdk: ~
$ hrt_model_exec perf \
--model_file <模型文件> \
--frame_count=200
要点

测极限帧率加 --thread_num=<N>：X5 是 1–8，S 系列是 1–32。

④ BPU 使用率root@rdk: ~
$ hrut_somstatus
$ hrut_somstatus | grep -A4 -i "bpu status"
$ hrut_somstatus | grep -A6 -i "bpu status"
要点

第一行 X5；第二行 S100 / S100P；第三行 S600（bpu0..bpu3）。

接着测 BPU 的纯推理性能。还是 hrt_model_exec，子命令换成 perf，跑 200 帧。四块板的语法完全一样。如果想测极限帧率，可以加上 thread_num 参数，X5 可以设 1 到 8，S 系列可以设 1 到 32。跑的同时，另开一个终端，执行 hrut_somstatus，看 BPU 使用率。X5 直接看 bpu status 那一段；S 系列输出比较长，用 grep 过滤一下就行，S600 能看到 bpu0 到 bpu3 四个核在一起工作。
