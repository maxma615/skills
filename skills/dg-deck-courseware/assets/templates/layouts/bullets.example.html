Model Format

模型格式不能混用

S 系列三块板用同一个工具链镜像；版本号以工具链文档为准。

  • ✕X5 的 .bin 不能在 S 系列上跑
  • ✕S100P 也不能用 S100 的 .hbm
  • ✕禁止把 .hbm 改后缀冒充 .bin
  • →X5 输入：一个 packed NV12 张量
  • →S 系列输入：Y、UV 两个张量
  • !例外：X5 走 QAT 产出 .hbm，本章不展开

这里有几条一定要记住。第一，四块板的模型不能混用：X5 的 .bin，不能在 S 系列上跑；S100P 也不能直接用 S100 的 .hbm。第二，千万别把 .hbm 改个后缀，冒充 .bin，这是明确禁止的。第三，输入形式也不一样：Model Zoo 里，X5 的模型输入是一个 packed NV12 张量，S 系列是 Y 和 UV 分开的两个张量。另外提一句例外：本课程的主线是 PTQ，X5 走 PTQ 产出 .bin；如果 X5 改走 QAT，产出的是 .hbm，那是另一条流程，本章不展开。
Rules

新手必记五条规则

每次动手转换前，先对照这五条。

01
march 和格式一一对应，不跨平台复用模型、Runtime、wheel 包
02
默认先走 PTQ，不达标再考虑 QAT
03
工具链用官方 Docker，在 x86 电脑上转换
04
先跑 checker 看算子分配，再准备校准数据和 YAML
05
每次转换后都测性能和精度；板端用系统自带的 hbm_runtime

最后，送大家五条新手必记的规则。一，march 和格式一一对应，不能跨平台复用模型、Runtime 或者 wheel 包。二，默认先走 PTQ，不达标再考虑 QAT。三，工具链用官方 Docker，在 x86 电脑上转换，板端只负责推理。四，先跑 checker 看算子分配，再准备校准数据和 YAML 配置。五，每次转换后，都要测性能和精度，不能只看"转换成功"；板端用系统自带的 hbm_runtime，不要去装 PyPI 上的同名包。
